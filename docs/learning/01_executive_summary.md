# 📋 MoveMap エグゼクティブサマリー

> **5 分で全体を語れる**ことを目的にしたサマリー。
> 顧客・上司・採用面接・自分のメンタルモデル整理に使う。
>
> 最終更新:2026-06-05(DEC-016 mode C 公開承認後)

---

## 1 行で言うと

**「全国 47 都道府県を 9 観点で比較・診断・予測できる、データドリブンの地方移住検討ツール。個人制作のポートフォリオ作品。」**

---

## なぜ作ったか(Problem)

| 課題 | 既存ツールの限界 |
|---|---|
| 地方移住を検討しても情報が散在 | 自治体 HP / SUUMO / 田舎暮らしの本 などバラバラ |
| 「結局どこが良い?」の判断軸が無い | データ羅列だけで意思決定支援が弱い |
| 将来の地域変化が見えない | 出生数・物価・地価の予測がほぼ無い |
| 50-60 代向けの可読性配慮が弱い | フォント小、操作迷子になりやすい(初期 UX 設計の主ターゲット) |
| 公開・共有しづらい | 個人ツール前提のものが多い |

---

## どう解いたか(Solution)

### 9 観点の統合スコア化(2026-05-26 治安 + 人口流入を追加)

| # | 指標 | データ源 | 単位 | 予測対象 |
|---|---|---|---|---|
| 1 | 💰 物価指数 | e-Stat 消費者物価地域差指数 | 2020=100 | ✅ |
| 2 | 🏘️ 地価 | 国交省 不動産情報ライブラリ(reinfolib) | 万円/㎡ | ✅ |
| 3 | 🏠 賃料相場 | e-Stat 令和5年 住宅・土地統計調査 | 万円/月 | ✅ |
| 4 | 👶 出生数 | e-Stat 人口動態統計 | 万人/年 | ✅ |
| 5 | 🌬️ 空気質 | WAQI(世界大気質指数) | AQI | ❌(static) |
| 6 | 🌀 災害リスク | 国土数値情報 | 0〜5 | ❌(static) |
| 7 | 🚆 交通アクセス | 国土数値情報(空港/新幹線/IC 距離) | 0〜5 | ❌(static) |
| 8 | 👮 治安 | e-Stat 警察庁犯罪統計 ÷ 県人口 ×1000 | **件/千人**(2026-06-05 千人率化) | ❌(scenario) |
| 9 | 📥 人口流入 | e-Stat 住民基本台帳人口移動報告 | ‰(転入超過率) | ❌(scenario) |

→ 各指標を**偏差値化(50=全国平均)** + 住みやすさ方向で反転 + 加重平均
→ **「住みやすさスコア」** として総合ランキング、47 県を 1 列に並べる

**予測対象 4 指標**:ARIMA + Prophet で 3/5/10 年先を予測、R² ≥ 0.6 のみ採用。
**予測対象外 5 指標**:`data_provider._simple_extrapolate()` で県別シナリオ外挿(三大都市圏 / 中核 / 地方郡部の 3 区分で年率補正)。

### UX の世界観(2026-06 リニューアル)

```
[ヒーロー:4 枚自動横スライド + 手動切替 + 朱の CTA「診断を始める」]
   ↓
[コンテンツ見出し]
   ↓ クリック型バナー(画像 + テキスト)
🎯 診断する │ 🗾 地図で見る │ 🏆 ランキング │ ⚔️ 比較で見る │ 📍 エリアを知る │ 🤖 AI予測
   ↓
[免責バナー / 出典 / 法務リンクフッター]
```

サイドバー廃止 + 全画面ワイドビジュアル + ヒーロー画像で「**移住の予感**」を演出。
各画面の左上に「🏠 TOPページ」ボタンで戻る、URL は `?view=KEY` で共有可能。

### AI 予測の透明性

- **ARIMA**(線形トレンド + 季節)+ **Prophet**(休日効果・変化点)を併用
- 主要 4 指標 × 47 都道府県 × 3 horizon = **564 件**の予測値
- **R² < 0.6** の予測は **`no_prediction`**(信頼性のために fallback)
- 「🤖 AI 予測」タブで モデル種類 / R² / MAE を全公開(INV-BIZ-003)

## 開発フロー(twin-build)

```
Phase 0 課題定義 → Phase 1 要求 → Phase 2 業務構造 → Phase 3 業務フロー →
Phase 4 システム要件 → Phase 5 アーキ → Phase 6 設計 → Phase 7 実装 →
Phase 8 レビュー
                → ローンチ P0-P4(運用準備) → DEC-016(mode C 解禁、公開判断)
                → SEO Tier 1(meta / JSON-LD)→ 47 県 LP(GitHub Pages、生成中)
                → 計測駆動(仮説 → GA4 イベント → T+14 振り返り)
```

- 各 Phase に **Coverage**(設計と実装の整合性チェック)と **Gate / DEC**(意思決定の記録)
- AI(Claude Code + twin-build MCP)が Phase ごとに設計書を生成 → ユーザー判断 → 次フェーズ
- 設計成果物は `outputs/00_problem.md` 〜 `outputs/99_review.md` に保存

## 現状の制約と次の打ち手

### 制約

- **粒度が都道府県止まり**(市区町村は Wikipedia 連携で部分対応のみ)
- **意思決定の出口**(物件・求人・自治体相談)が無い
- **写真・動画・移住経験者の声** などの定性情報は AI 生成記事で補完予定
- **個人最適化** はスライダーと診断のみ(AI チャット相談無し)
- **ホスティング**:Streamlit Cloud デプロイ予定(2026-06-05 時点で承認済、デプロイ作業中)

### 短期(~1ヶ月)の打ち手

1. **Streamlit Cloud デプロイ + GA4 Secrets 設定**(残作業)
2. **47 県の魅力記事自動生成 + GitHub Pages 公開**(SEO Tier 2 突破、無料)
3. **計測駆動の T+14 仮説検証**(GA4 カスタムイベント + 振り返り)
4. **note 記事公開**(被リンク獲得)

### 中期の打ち手候補(検討段階)

1. **AI 移住アドバイザー**(Claude API でチャット相談)
2. **市区町村ドリルダウン**
3. **物件・求人・支援金連携**(SUUMO アフィ等)
4. **自治体向け B2B SaaS / API**

## 用語集(顧客説明・面接で使う)

- **偏差値**: 平均 50、標準偏差 10 で正規化したスコア。60 以上で「平均より良い」、70 以上で「全国トップクラス」
- **住みやすさスコア**: 9 指標の偏差値を住みやすさ方向で揃えて(重み付け)平均したもの
- **ARIMA / Prophet**: 時系列予測モデル。ARIMA は線形トレンド + 季節、Prophet は休日効果や変化点に強い
- **R²(決定係数)**: モデル予測の説明力。1 に近いほど精度高、0.6 未満は本アプリでは予測無効
- **VSA(Vertical Slice Architecture)**: 機能単位でフォルダを切る設計手法。レイヤ別ではなく Usecase 別
- **twin-build**: AI 駆動開発のフェーズ管理フレームワーク。Phase 0〜8 のガバナンスを提供
- **DEC / GATE / INV**: 設計判断ログ / 人間判断ゲート / 不変条件
- **mode A/B/C**: ホスティング形態(A=ローカル / B=認証付き限定共有 / C=完全公開)。DEC-016 で C 解禁
- **計測駆動開発**: 公開前に仮説を数値で書く → GA4 イベントで計測 → 14 日後に振り返る、のループ

# 📋 MoveMap エグゼクティブサマリー

> **5 分で全体を語れる**ことを目的にしたサマリーです。
> 顧客への初回説明、社内共有、自分のメンタルモデル整理に使えます。

---

## 1 行で言うと

**「50-60 代の地方移住検討者向けに、47 都道府県を 7 つの観点で比較・診断・予測できる Web アプリ」**

---

## なぜ作ったか(Problem)

| 課題 | 既存ツールの限界 |
|---|---|
| 地方移住を検討しても情報が散在 | 自治体 HP / SUUMO / 田舎暮らしの本 などバラバラ |
| 「結局どこが良い?」の判断軸が無い | データ羅列だけで意思決定支援が弱い |
| 将来の地域変化が見えない | 出生数・物価・地価の予測がほぼ無い |
| 50-60 代向けの可読性配慮が弱い | フォント小、操作迷子になりやすい |

---

## どう解いたか(Solution)

### 7 観点の統合スコア化

| 指標 | データ源 | 単位 |
|---|---|---|
| 💰 物価指数 | e-Stat 消費者物価指数 | 2020=100 |
| 🏘️ 地価 | 国交省 不動産情報ライブラリ | 万円/㎡ |
| 🏠 賃料相場 | e-Stat 令和5年 住宅・土地統計調査 | 万円/月 |
| 👶 出生数 | e-Stat 人口動態統計 | 万人/年 |
| 🌬️ 空気質 | WAQI(世界大気質指数) | PM2.5/AQI |
| 🌀 災害リスク | 国土数値情報(地震/洪水/土砂) | 0〜5 スコア |
| 🚆 交通アクセス | 国土数値情報(空港/新幹線/IC 距離) | 0〜5 スコア |

→ 各指標を**偏差値化(50=全国平均)** + 住みやすさ方向で反転 + 平均
→ **「住みやすさスコア」** として総合ランキング

### 6 タブの UX 設計

```
🎯 診断 → 🗾 地図 → 🏆 順位 → ⚔️ 比較 → 📍 詳細 → 🤖 AI根拠
(オンボーディング)(可視化)  (絞り込み)(2県比較) (詳細表)  (透明性)
```

### AI 予測

- **ARIMA** + **Prophet** をアンサンブル
- 4 主要指標(物価/地価/賃料/出生)について **3 / 5 / 10 年先** の予測値
- R² < 0.6 の予測は **`no_prediction`** として fallback(信頼性確保)

## 技術スタック(なぜこれを選んだか)

| レイヤ | 採用 | 選定理由 |
|---|---|---|
| **UI** | Streamlit + Plotly | Python だけで Web UI 完結、個人ツール最速 |

| **デプロイ** | ローカル(個人) → ngrok 一時公開 | DEC-005「個人ツール限定」決定に従う |
| **AI 駆動開発** | twin-build フロー | Phase 0〜8 の構造化された開発ガバナンス |

## 開発の進め方(twin-build フロー)

```
Phase 0 課題定義 → Phase 1 要求 → Phase 2 業務構造 → Phase 3 業務フロー →
Phase 4 システム要件 → Phase 5 アーキ → Phase 6 設計 → Phase 7 実装 →
Phase 8 レビュー → 運用準備(P0-P4) → 実 API 連携 → UI/UX 強化 → 仕様検討
```

- 各 Phase に **Coverage**(設計と実装の整合性)と **Gate**(意思決定の記録)が紐づく
- AI(私)が Phase ごとに対話形式で設計書を生成、ユーザーが判断 → 次フェーズへ
- 設計成果物は `outputs/00_problem.md` 〜 `outputs/99_review.md` に保存

## データソース連携で得た教訓

| ソース | 想定 | 実際 | 教訓 |
|---|---|---|---|
| **e-Stat 物価** | 都道府県別 CPI | area=`13A01`(県庁所在地) | API 仕様は実レスポンスで確認しないと分からない |
| **e-Stat 出生** | `0003411634` で取れる | 全国計のみ。`0003412062` に差し替えで都道府県別 OK | 統計表 ID は検索 API で実証必須 |
| **reinfolib 地価** | `area=1`(整数) | `area="01"`(2桁ゼロパディング文字列)で 200 | エラーメッセージから推測可能、初手で probe 必須 |
| **reinfolib XCT001** | 「不動産価格指数」 | 実は **地価公示** を返す | API 名称と中身が一致しない場合がある |
| **そらまめ君** | JSON 配信 | HTML SPA に変わっていた(配信廃止) | 公的 API でも仕様変更あり、代替候補(WAQI 等)を持っておく |
| **CPI cat01=0047(民営家賃)** | 都道府県別 | 東京都区部+全国のみ | 「絞り込む」と取れる範囲が変わることがある |

## 現状の制約と次の打ち手

### 制約
- **粒度が都道府県止まり**(市区町村は未対応)
- **意思決定の出口**(物件・求人・自治体相談)が無い

- **個人最適化** はスライダーと診断のみ(AI チャット相談無し)
- **ホスティング** は個人 PC + ngrok 一時公開のみ

## 用語集(顧客説明で使う)

- **偏差値**: 平均 50、標準偏差 10 で正規化したスコア。60 以上で「平均より良い」
- **住みやすさスコア**: 7 指標の偏差値を住みやすさ方向で揃えて(重み付け)平均したもの
- **ARIMA / Prophet**: 時系列予測モデル。ARIMA は線形トレンド + 季節、Prophet は休日効果や変化点に強い
- **R²(決定係数)**: モデル予測の説明力。1 に近いほど精度高、0.6 未満は本アプリでは予測無効
- **VSA(Vertical Slice Architecture)**: 機能単位でフォルダを切る設計手法。レイヤ別ではなく Usecase 別
- **twin-build**: AI 駆動開発のフェーズ管理フレームワーク。Phase 0〜8 のガバナンスを提供

# MoveMap プライバシーポリシー

**最終改定日**: 2026-05-30
**制定日**: 2026-05-30
**運営者**: 神山隆憲(個人)

---

## 第1条(本ポリシーの目的)

本ポリシーは、運営者(神山隆憲)が個人として運営するウェブアプリケーション「MoveMap」(以下「本サービス」)における、利用者の個人情報・利用情報の取扱いについて定めるものです。

## 第2条(本サービスの基本方針)

1. 本サービスは **認証なし・閲覧専用** のサービスであり、原則として利用者の個人情報を取得しません。
2. 本サービスはアカウント登録機能を持たず、氏名・住所・電話番号・メールアドレス等を取得しません。
3. 本サービスはお問い合わせフォーム等の双方向通信機能を提供しません(連絡は GitHub Issue 経由)。

## 第3条(取得する情報)

### 3.1 現在(2026-05-30 時点)取得している情報

本サービスは現時点で利用者の個人情報を取得していません。

### 3.2 ホスティング事業者(Streamlit Community Cloud)による技術的ログ

本サービスは Streamlit Community Cloud(Snowflake Inc. が提供)上で動作しており、同サービスがインフラ運用上、以下の情報を技術的に記録する可能性があります。

- 接続元 IP アドレス
- ユーザーエージェント(ブラウザ種別)
- アクセス時刻
- アクセスした URL

これらは **Streamlit Community Cloud のプライバシーポリシー** に従って取り扱われ、運営者は直接アクセスできません。詳細は [Streamlit Cloud Privacy Policy](https://streamlit.io/privacy-policy) をご確認ください。

### 3.3 将来 Google Analytics 4 等の解析ツールを導入した場合

将来的にアクセス解析を導入する場合、以下の匿名化された情報を取得する可能性があります。

- 訪問者数(ユニーク・延べ)
- ページビュー数
- 滞在時間
- 参照元 URL(リファラ)
- 画面解像度・OS・ブラウザ種別
- 概略の地理情報(国・地域、市区町村単位までは取得しない)

これらは個人を特定しない統計情報として取得・利用します。

## 第4条(利用目的)

第3条で取得した情報は、以下の目的でのみ利用します。

1. 本サービスの利用状況の把握(アクセス数・閲覧傾向の分析)
2. 本サービスの機能改善・不具合修正
3. ポートフォリオ・学習成果としての利用状況集計

商用利用・第三者への販売・広告配信・プロファイリング目的での利用は行いません。

## 第5条(Cookie および類似技術)

### 5.1 現状

本サービスは現時点で運営者が独自に設定する Cookie を使用していません。

### 5.2 Streamlit Community Cloud による Cookie

ホスティング事業者(Streamlit Community Cloud)がセッション管理・負荷分散等の目的で Cookie を使用する場合があります。詳細は同事業者のポリシーをご確認ください。

### 5.3 将来 Google Analytics 4 を導入する場合

将来 Google Analytics 4(以下「GA4」)を導入する場合、以下の対応を行います。

1. GA4 が使用する `_ga` 等の Cookie を利用者のブラウザに保存します。
2. 本サービストップ画面で **Cookie 同意バナー** を表示し、利用者の同意を得た後に GA4 を有効化します(オプトイン方式)。
3. 利用者は同意を拒否した場合、GA4 による計測は行われません。
4. 利用者はブラウザ設定で Cookie を削除・拒否することにより、本サービスでの計測を無効化できます。

## 第6条(第三者提供)

運営者は、利用者の事前の同意なく、取得した情報を第三者に提供しません。ただし、以下の場合を除きます。

1. 法令に基づく場合
2. 人の生命・身体・財産の保護のために必要であって、本人の同意取得が困難である場合
3. 統計データとして個人を識別できない形に加工した場合

## 第7条(外部サービスへのデータ送信)

本サービスは、以下の外部サービスにデータを送信する可能性があります。

| 送信先 | 送信内容 | 目的 |
|---|---|---|
| Streamlit Community Cloud | 接続ログ(IP、UA、URL) | ホスティング技術運用 |
| OpenStreetMap | 地図タイル取得リクエスト | 地図表示 |
| Wikipedia / Wikidata | 市区町村情報取得リクエスト | 市区町村セクション表示 |
| Google Analytics 4(導入時のみ・同意後) | 匿名化アクセス情報 | アクセス解析 |

これらの送信先における情報の取扱いは、各事業者のプライバシーポリシーに従います。

## 第8条(データの保存期間)

1. 運営者が直接管理する利用者情報はありません(第2条)。
2. GA4 導入時、計測データの保存期間は最短設定(14ヶ月)とします。

## 第9条(利用者の権利)

利用者は、本サービスに関連して以下の権利を有します。

1. **開示請求**: 取得された自己の情報の開示を求めること
2. **訂正・削除請求**: 取得された自己の情報の訂正・削除を求めること
3. **利用停止請求**: 自己の情報の利用停止を求めること

ただし、本サービスは原則として個人を特定可能な情報を取得していないため、開示・訂正・削除の対象となる情報が存在しない場合があります。請求方法は第11条のお問い合わせ窓口をご利用ください。

## 第10条(セキュリティ)

1. 本サービスのソースコードは GitHub 上で管理され、認証情報・API キーはコードから分離して `.env` ファイル等の安全な手段で管理されます。
2. ホスティング事業者(Streamlit Community Cloud)の HTTPS 通信により、ブラウザと本サービス間の通信は暗号化されます。

## 第11条(お問い合わせ窓口)

本ポリシー・個人情報の取扱いに関するお問い合わせは、以下の窓口で受け付けます。

- **GitHub Issue**: [takanorikoyama-dev/MoveMap](https://github.com/takanorikoyama-dev/MoveMap)

メール窓口は現時点で提供しません。GitHub アカウントをお持ちでない場合は、Issue の利用にあたって GitHub の無料アカウント作成をお願いします。

## 第12条(本ポリシーの改定)

1. 本ポリシーは法令の改正・本サービスの仕様変更等に応じて、運営者の判断で改定する場合があります。
2. 重要な変更がある場合は、本サービス上で告知します。
3. 改定後のポリシーは、本サービス上に掲載した時点から効力を生じます。

## 第13条(準拠法)

本ポリシーの解釈および個人情報の取扱いに関する紛争には、日本法(個人情報保護法を含む)を準拠法とします。

## F2: 利用フロー(ShowMap)

```mermaid
sequenceDiagram
    actor User
    participant Streamlit
    participant DuckDB

    User->>Streamlit: アプリにアクセス
    Streamlit->>DuckDB: 47都道府県マスタ取得
    DuckDB-->>Streamlit: Prefecture × 47
    Streamlit->>DuckDB: Indicator マスタ + DataSource 取得
    DuckDB-->>Streamlit: Indicator × 7 + DataSource
    Streamlit->>DuckDB: CurrentValue(指標=物価, 全47件)
    DuckDB-->>Streamlit: 値 × 47
    Streamlit->>DuckDB: PredictedValue(指標=物価, horizon=現在)
    DuckDB-->>Streamlit: 該当なし(現在は予測対象外)
    Streamlit-->>User: 47都道府県MAP表示<br/>(免責バナー + 出典 + 凡例)

    Note over User,Streamlit: 指標切替

    User->>Streamlit: 指標を「地価」に切替
    Streamlit->>DuckDB: CurrentValue(指標=地価)
    DuckDB-->>Streamlit: 値 × 47
    Streamlit-->>User: 地価ヒートマップ再描画

    Note over User,Streamlit: 年次切替

    User->>Streamlit: 年次を「5年後」に切替
    Streamlit->>DuckDB: PredictedValue(指標=地価, horizon=5)
    DuckDB-->>Streamlit: 予測値 × 47(quality_status 含む)
    Streamlit-->>User: 5年後予測ヒートマップ<br/>(no_prediction 都道府県は灰色)

    Note over User,Streamlit: 都道府県詳細

    User->>Streamlit: 都道府県クリック(例: 沖縄県)
    Streamlit->>DuckDB: 沖縄県の全指標(現在+予測)取得
    DuckDB-->>Streamlit: 詳細データセット
    Streamlit-->>User: 詳細パネル表示
```

### 例外パターン

- **C-06 DB 接続失敗**: Streamlit が DuckDB へのアクセス失敗 → ローカルキャッシュ表示 → なければエラー画面
- **C-07 描画失敗**: Plotly レンダリング失敗 → 単純再描画 retry → 連続失敗時はエラーバナー

## F1: 月次データ更新フロー(RunBatch)

```mermaid
sequenceDiagram
    participant Scheduler
    participant ETL
    participant External
    participant DuckDB
    participant Model

    Scheduler->>ETL: 月初 02:00 JST 起動
    ETL->>DuckDB: BatchJob C (status=running)
    DuckDB-->>ETL: BatchJob.id

    loop 各データソース(e-Stat, 地価, 賃料, 空気, 災害, 交通)
        ETL->>External: If-Modified-Since で差分判定
        alt 未更新
            External-->>ETL: 304 Not Modified
            Note over ETL: スキップ
        else 更新あり
            External-->>ETL: 200 + データ
            ETL->>ETL: 正規化(都道府県コード・単位・型)
            ETL->>DuckDB: CurrentValue upsert
            ETL->>DuckDB: HistoricalValue append
        end
    end

    ETL->>Model: 再学習トリガー(主要4指標)

    loop 主要4指標(物価/地価/賃料/出生数)
        Model->>DuckDB: HistoricalValue 取得
        DuckDB-->>Model: 履歴データ
        Model->>Model: 時系列モデル学習(ARIMA or Prophet)
        Model->>Model: R²/MAE 計算
        Model->>DuckDB: PredictionModel C, ModelEvaluation C

        alt R² ≥ 0.6
            Model->>Model: 47都道府県 × 3時点 の予測値生成
            Model->>DuckDB: PredictedValue upsert (quality_status=good)
        else R² < 0.6
            Note over Model: 該当指標を no_prediction
            Model->>DuckDB: PredictedValue upsert (quality_status=no_prediction)
        end
    end

    Model->>DuckDB: BatchJob U (status=success/partial/failure)
    Model->>DuckDB: AuditLog C (完了ログ)
```

### 例外パターン

- **C-01 外部API失敗**: 指数バックオフ 3 回 → 失敗時は前回値保持(R1.3)、UI に「未更新」
- **C-02 3 回連続失敗**: UI に警告通知、バッチログ記録
- **C-03 DB 書き込み失敗**: Retry → 失敗時はトランザクション巻き戻し
- **C-04 R² < 0.6**: フォールバック「予測なし」表示
- **C-05 学習プロセス失敗**: Retry 1 回 → 失敗時は旧モデル+旧予測値維持
- **EX-003 バッチ全体失敗**: BatchJob.status='failure' 記録、次回バッチで前回値維持

## シーケンス対象外の Usecase

| Usecase | 理由 |
|---------|------|
| `SwitchIndicator` | ShowMap の一部、Mermaid 化不要 |
| `SwitchHorizon` | 同上 |
| `ShowPrefectureDetail` | 同上(上記 F2 内に表現済み) |
| `ShowModelDetail` | 単純な DB 読込→表示で図示不要 |
| `ShowDisclaimer` | 静的UI、図示不要 |
| `ShowDataSources` | DataSource 読込→ラベル表示、図示不要 |
| `FetchExternalData`/`NormalizeData`/`UpsertCurrentValues`/`AppendHistory`/`RetrainModels`/`EvaluateModels`/`GeneratePredictions`/`ApplyFallback`/`LogBatchOutcome` | RunBatch のサブステップとして上記 F1 内に表現済み |

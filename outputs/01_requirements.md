## 背景(Why)

### なぜこのプロジェクトが必要か

ユーザー自身が「今・これから移住を計画的に検討する」ためのツールが必要だが、市場に該当ツールが存在しない。
個人ニーズ駆動で MVP を作り、自分が意思決定に使える状態を作ることが目的。

副次的に、AI 時系列予測モデルを移住検討文脈に適用するという**技術的探索**の側面もある。

### 現状の課題がもたらす影響(放置した場合)

- ユーザー本人および同世代(50-60代セカンドキャリア層)が、Excel に手作業で集計する非効率な状態が続く
- 「複数地域 × 複数指標 × 長期予測」の意思決定材料が揃わず、移住判断を先送り、または直感で決めてしまう
- 個人にとっては老後の住みかえという**取り返しのつかない決定**でリスクが顕在化

## 実現したい状態(What)

### ゴールの状態

- 全国47都道府県を MAP 上で並列に**定量比較できる**ようになる
- 7つの指標を**ヒートマップ的に可視化**して感覚的に地域特性を掴めるようになる
- **3年・5年・10年後の予測値**を AI モデルで参照できるようになる
- AI 予測モデルの根拠(使用変数・モデル評価指標)を確認できる

### 具体的な要求

1. **MAP UI**: 47都道府県を地理的に表示、指標切替・年次切替ができる
2. **7指標の可視化**: ヒートマップ/階級区分で1画面で全国を見渡せる
3. **AI 予測モデル**: 各指標について 3/5/10年の予測値を返す
4. **モデル透明性**: 使った変数・モデル種別・評価指標(MAE/R²等)が確認できる
5. **時系列スライダー**: 現在 → 3年 → 5年 → 10年を時系列で切り替え

## 成功の定義

### KGI(最終目標)

**「7指標 × 47都道府県 × 現在/3年/5年/10年予測値を欠落なく表示できるツールが完成している状態」**

### KPI(中間指標)

| KPI | 目標値 | 測定方法 |
|------|--------|----------|
| 現在値被覆率(Must) | 100%(**7指標** × 47都道府県 × 現在値) | データセル充足率の自動計測 |
| 予測値被覆率(Must) | 100%(**主要4指標**(物価・地価・賃料・出生数) × 47都道府県 × 3時点(3/5/10年)) | 同上 |
| 予測モデル評価指標(主要4指標) | R² ≥ 0.6 または MAE 基準値以下 | クロスバリデーション |
| MAP UI 機能完成度 | 全機能(地図表示・指標切替・年次切替・モデル詳細参照)が動作 | チェックリスト |

## スコープ

### Must(必須)

- [ ] 全国47都道府県を対象とした地域比較 MAP UI
- [ ] 7指標の MAP 可視化:
  - [ ] 物価指数
  - [ ] 地価
  - [ ] 賃料相場
  - [ ] 出生数(将来性指標として)
  - [ ] 環境(空気の綺麗度)
  - [ ] 災害リスク(地震・津波・土砂・洪水)
  - [ ] 交通アクセス(空港・新幹線・高速IC)
- [ ] 各指標(7つすべて)の現在値の表示
- [ ] 3年 / 5年 / 10年後の AI 予測値の表示(**主要4指標のみ**: 物価指数・地価・賃料相場・出生数) ← A-01 を受けて絞り込み
- [ ] AI 予測モデルの根拠ページ(使用変数・モデル種別・評価指標)
- [ ] 個人利用前提の免責表示(投資/意思決定の最終責任はユーザー)

### Should(重要)

- [ ] **指標カスタム重み付け**(ユーザーが重視する指標に重みを付けてランキング) ← A-02 を受けて Could から昇格
- [ ] **環境(空気)・災害リスク・交通アクセス の AI 予測値表示** ← A-01 を受けて Must の予測対象から移動
- [ ] 医療アクセス指標の追加(人口あたり医師数/病院数)
- [ ] 市区町村粒度への段階拡張(都道府県で絞り込んだ後の詳細閲覧)
- [ ] 口コミ・コミュニティ雰囲気等の質的情報の取り込み

### Could(あれば嬉しい)

- [ ] 気候指標の追加(平均気温・降雪量・日照時間)
- [ ] 過去推移(時系列グラフ)表示

### やらないこと(Out of Scope)

- 個別物件の紹介・仲介 — SUUMO/LIFULL HOME'S 領域
- 移住あっせん・行政手続支援 — 自治体・移住エージェント領域
- 海外移住・日本以外の地域
- **商用展開・収益化機能** — DEC-016 後も商業展開はしない(課金・広告・有料機能なし)
  - ~~公開機能~~ → DEC-016 で mode C(認証なし完全公開)を解禁、ポートフォリオ用途で Streamlit Cloud Public 利用
- **認証・ユーザー管理** — 個人ツール限定のため不要
- 仲介業者への問合せ機能、売買決済機能

## 法的・倫理面の方針

個人ツール限定とはいえ、AI 予測値を表示する以上、以下を明示する:

- **免責表示**: 「本ツールは個人利用を目的とした参考情報であり、投資判断・意思決定の最終責任はユーザーにある」
- **データ出典の明示**: 各指標のデータ出典(e-Stat 等)を必ず表示
- **モデルの限界の明示**: 予測値には不確実性があり、未来を保証するものではない旨を明示
- **将来公開する場合の論点**: 公開時には不動産公正競争規約・金融商品取引法等の解釈を再点検する必要あり

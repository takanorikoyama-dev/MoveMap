## 背景

DEC-005(2026 Phase 1 確定)で「個人ツール限定・認証なしクローズド利用」と決定した。
当時、R-01(市場規模)/R-02(リピート利用)/R-03(法的リスク)/R-05(競合差別化)を一括解消する判断として有効であった。

しかし launch 後(2026-05-18)以降、以下のニーズが発生:

1. **ポートフォリオ目的の URL 共有**:転職活動 / GREE 社内 / 知人への提示で「触ってもらえる demo URL」が欲しい
2. **Vercel ライクな共有体験**:認証なしでアクセスし即操作可能な公開リンク
3. **mode B(認証付き)では UX が損なわれる**:1-2 名共有なら成立するが、不特定多数想定では認証摩擦が大きい

## 論点

**Q. MoveMap の公開形態を mode A/B から mode C(完全公開)に拡張すべきか?**

## 選択肢

### Opt-A: DEC-005 維持(現状継続)
- 公開形態: mode A(ローカル) + mode B(認証付き限定共有)のみ
- 共有手段: Tailscale Funnel / ngrok / 同席閲覧
- メリット: 法的リスクなし、追加実装ゼロ
- デメリット: ポートフォリオ用途で URL を渡せない、デモ体験が悪い

### Opt-B: DEC-005 を新 DEC で上書き、mode C を解禁(本案)
- 公開形態: mode A + B + **C(完全公開)** を併用許可
- 公開先: Streamlit Community Cloud Public
- 必須対応:
  - 利用規約・プライバシーポリシー作成
  - 免責表示(INV-BIZ-005)の強化
  - Cookie 同意バナー検討(GA4 導入時)
  - 「投資助言ではない」「移住助言ではない」明示の強化
- メリット: ポートフォリオ用途で URL 共有可、demo 体験良好
- デメリット: 法的リスクが復活、利用規約等の整備工数が発生

### Opt-C: 別プロジェクトとして新規立ち上げ
- MoveMap 本体は DEC-005 維持
- 公開版は新ワークスペースで Phase 0 から再走
- メリット: クリーンな切り分け、本体のシンプルさ保持
- デメリット: 過剰な工数(同じものを 2 つ管理)、ROI 低

## 結論

**Opt-B を採用** — DEC-005 を本 DEC-016 で上書きし、mode C を解禁する。

## 理由

- 個人ポートフォリオ目的のため、商業展開ではなく **「成果物の見せ場」としての公開** に限定される
- 「投資助言ではない」「個人制作」を明示することで R-03 の主要論点(不動産公正競争規約・金商法)は**注意書きで軽減可能**な水準
- 別プロジェクト化(Opt-C)は工数過大、本体に手を入れる方が合理的
- 認証付き限定共有(mode B)を残しつつ mode C も**選択肢として追加**する形を取る(排他ではない)

## R-03 の再オープンと対応方針

| 法令・規約 | 想定リスク | 対応 |
|---|---|---|
| **不動産公正競争規約** | 地価/賃料予測の表示が広告規制の対象になり得る | 「公的統計の機械的延長であり、不動産取引の参考情報ではない」明示 |
| **金融商品取引法** | 投資判断材料として用いられた場合の助言業該当 | 「投資助言ではない」「投資判断は自己責任」明示 |
| **個人情報保護法** | アクセスログ・Cookie 収集 | プライバシーポリシー作成、GA4 導入時は Cookie 同意バナー |
| **利用規約整備** | 個人ツール時の免責では不十分 | 簡易利用規約を `legal/terms.md` として整備、UI フッターからリンク |

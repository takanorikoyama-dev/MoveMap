# 課題定義

## 作成日
2026-05-16

## 誰の(Who)

**主軸ペルソナ: 50-60代、セカンドキャリア / リタイア前後の層**

- ライフステージ: 子どもが独立し、定年後または定年前後の住み替えを検討
- 関心軸:
  - 老後の住みやすさ(資産価値の安定性、災害安全性)
  - 都市部との往来のしやすさ(家族・旧交との接点維持)
  - 長期(10年スパン)で見た地域の将来性
- 想定利用シーン:
  - 移住先候補を「ざっくり比較」する初期検討フェーズ
  - 数年スパンで地域を眺めながら意思決定を熟成させる
- 副次ターゲット: ユーザー本人(GREE 社員、移住検討中)を含む同世代

## どんな困りごとを(Problem)

### 現状

地方移住を検討するとき、複数の地域を**定量データと将来予測の両軸で**横並び比較できる手段がない。

- 物価、地価、賃料相場、人口動態、環境などの個別データは公的統計に存在するが、**サイトを横断して集める手間が大きい**
- 既存の不動産系メディア(SUUMO、LIFULL HOME'S 等)は「現時点の物件情報」が中心で、**将来予測がない**
- 自治体の移住情報サイトはアピール中心で、**他地域との客観比較が困難**
- 移住検討者は自力で Excel に整理する状態

### 原因・背景

- データの所在が分散している(政府統計、気象庁、国土地理院、ハザードマップ等)
- 「3-10年後にこの地域がどうなるか」を扱った可視化ツールが日本市場で薄い
- AI による時系列予測の技術はあるが、移住検討文脈での実装例が少ない

## どんな状態にしたいか(Desired State)

- 全国47都道府県を MAP 上で並列に**定量比較できる**ようになる
- 7つの指標を**ヒートマップ的に可視化**して感覚的に地域特性を掴めるようになる
- **3年・5年・10年後の予測値**を AI モデルで参照できるようになる
- 予測モデルの根拠(どの変数を使い、どう推計したか)を確認できるようになる(透明性は Phase 1 で詳細化)

## スコープ

### やること(In Scope)

- [ ] 全国47都道府県を対象とした地域比較 MAP
- [ ] 以下の Must 指標を MAP に可視化(7指標)
  - [ ] 物価指数
  - [ ] 地価
  - [ ] 賃料相場
  - [ ] 出生数(将来性指標として)
  - [ ] 環境(空気の綺麗度)
  - [ ] 災害リスク(地震・津波・土砂・洪水)
  - [ ] 交通アクセス(空港・新幹線・高速IC)
- [ ] 各指標の現在値の表示
- [ ] 3年 / 5年 / 10年後の AI 予測値の表示
- [ ] AI 予測モデルの参照(粒度は Phase 1 で決定)

### やらないこと(Out of Scope)

- 個別物件の紹介・仲介(不動産物件データベース)
  - 理由: SUUMO/LIFULL HOME'S の領域。本プロダクトは「地域選び」に集中
- 移住あっせん・行政手続支援
  - 理由: 自治体・移住エージェントの領域。意思決定支援に限定
- 海外移住・日本以外の地域
  - 理由: データソース統一が困難。MVP は日本国内に閉じる

### 未確定(Phase 1 以降で再検討)

- 口コミ・コミュニティの雰囲気等の質的情報の扱い
  - Phase 0 では除外せず、Phase 1 で「Should/Could」として検討
- 医療アクセス・気候指標の追加
  - 今回 Must には入れなかったが、Should/Could 枠で復活させる余地あり

### 前提条件

- 新規開発(既存システム・移行制約なし)
- 開発体制: 個人開発を起点とし、必要に応じて拡張
- データソース: 政府統計(e-Stat 等)・気象庁・国土地理院・ハザードマップポータル等の**公的統計を中心**に組む想定
- 想定リリース時期・予算: 未確定(Phase 1 で要検討)
- プロダクトの公開形態(個人ツール / 公開無料 / フリーミアム)は未決定 (DEC-004)
